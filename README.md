# Lanius Films

Static portfolio site for **Lanius Films**.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of `laniusfilms/laniusfilms.github.io`.
2. In GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The site should publish at `https://laniusfilms.github.io`.
